## 2. Mom Test 워크북

### 페르소나

4×4 **부분 마방진**(빈칸 2개, 1~16, 10라인 합 34) — **손/코드 학습자**. 최근: **OO 과제**.

### 인터뷰 답변 (과거 사실)

| # | 멘토 질문 요지 | 학습자 답변 (원문) |
|---|----------------|-------------------|
| — | 지난주 OO 과제 | 「지난주 OO 과제에서 빈칸 2개 넣고 행·열·대각선 합 맞췄는데 **대각선 하나를 빼먹어서 20분 날렸다**.」 |
| 2 | 20분 동안 반복 행동 | 「**숫자를 바꿔넣어봤어**」 |
| 3 | ‘맞다’고 본 기준 | 「**행 합만 34**」 |
| 4 | 대각선 누락 인지 | 「**직접 대각선 합 적어봤어**」 |
| 5 | 대각선 적기 직전 | 「**빈칸 숫자가 또 안맞았어**」 |
| 6 | ‘안 맞다’ 근거 | 「**열합이 34가 아니었어**」 |
| 7 | 열합 불일치 직후 | 「**숫자 다시 바꿔넣었어**」 |
| 8 | 두 번째 변경 시 확인 | *(미응답)* |

### 표면 문제 (금지)

- 「**대각선까지 자동 검증하는 프로그램**을 만든다」
- 「빈칸 2개 **자동 Solver**를 만든다」
- 「**ECB/TDD 워크벤치**를 만든다」

### 진짜 문제 (한 문장)

4×4 부분 마방진에서 빈칸을 맞출 때 **‘맞다’고 볼 검산 기준과 순서가 흔들려** 행합만 맞다고 보고 숫자를 반복 바꿔 넣다가, 열합·대각선 불일치를 **뒤늦게** 알아차리며 **같은 시행착오에 20분**을 쓴다.

### Mom Test 증거 3줄

1. 「**대각선 하나를 빼먹어서 20분 날렸다**」
2. 「**행 합만 34**」
3. 「**빈칸 또 안 맞음** → **열합 34 아님** → **직접 대각선 합**」

---

## 3. 행동·판정 타임라인

```
[빈칸 채우기] → 행합만 34 (~20분, 숫자 반복 변경)
  → 열합 ≠ 34 → 다시 변경 → 빈칸 불일치 → 대각선 합 직접 → 대각 누락 인지
```
