## 페르소나 (고정)

4×4 **부분 마방진** — 빈칸(`0`) **2개**, 값 **1~16**, **10라인**(4행·4열·2대각) 합 **34** — **손/코드 학습자**

---

## ① 인터뷰 시작

```
MagicSquare Mom Test. 페르소나: 부분 마방진(빈칸 2개) 학습자.
Mom Test 규칙 준수. 질문 1개만. 솔루션 금지.
```

**상세 규칙 (필요 시 추가):**

```
MagicSquare_1004 STEP 1 — Mom Test 인터뷰를 진행해.
너는 스타트업 멘토(Rob Fitzpatrick Mom Test 스타일)야.
나는 [페르소나: 4×4 부분 마방진(빈칸 2개, 1~16, 합 34) 학습자] 역할이야.

규칙:
1. 한 번에 질문 1개만
2. 금지: "만들면 좋겠어?", "이 기능 필요해?", "TDD/PyQt/Cursor 하면 어때?"
3. 허용: "마지막으로 ~했을 때", "그때 몇 분 걸렸어?", "뭐 때문에 포기했어?"
4. 내 답이 모호하면 추궁 1개만
5. 내가 솔루션 말하면 "그건 나중" 하고 불편으로 되돌려

먼저 인터뷰 질문 1개만 해. 솔루션 언급 금지.
```

**첫 질문 예시:**

> 4×4 **부분 마방진**(빈칸 2개)을 **마지막으로** 손으로 풀거나 코드로 건드린 때, **맨 처음에 실제로 한 일**이 뭐였나요?

---

## ② 답변 후

```
[답변] → 사실성 평가 + 다음 추궁 1개 + 불편 요약
```

**멘토 출력 형식 (권장):**

1. **사실성:** 과거형·구체 행동·시간 있는지 (✅/△)
2. **추궁 1개:** 모호하면만
3. **불편 요약:** 솔루션 없이 비용·판정·재현 한 줄

---

## ③ 종료

```
인터뷰 종료 → 표면 vs 진짜 문제 1문장 + Mom Test 증거 3줄
```

**상세:**

```
Mom Test 인터뷰 종료.

다음만 출력:
1. 표면 문제 (잘못된 정의) — "~~프로그램 만든다" 류
2. 진짜 문제 (한 문장) — 불편·비용·판정·재현 중심, 솔루션 이름 없음
3. Mom Test 증거 3줄 (내 답에서 인용)
```

## 프롬프트 — 워크북 채점

```
아래 Mom Test 결과를 채점해줘. 수정하지 마.
[워크북 전체]

체크:
- [ ] 미래 가정("~하면 좋겠다") 없음
- [ ] 과거 행동·시간·실수 구체성 있음
- [ ] 진짜 문제에 솔루션名(TDD/PyQt/Cursor) 없음
- [ ] 표면 문제와 진짜 문제가 분리됨
- [ ] MagicSquare 도메인(4×4, 10선, 34, 빈칸 2개) 반영

점수 /10 + 고칠 질문 1개만 제안
```
